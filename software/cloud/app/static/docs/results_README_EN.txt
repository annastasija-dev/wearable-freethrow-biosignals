Finished sessions are stored here after Finish session.

Each session is a folder, e.g. 2026-08-12_1430_P001

Inside:
  protocol/session.json — participant and session
  protocol/shots.jsonl — Hit / Miss
  raw/accelerometer.jsonl — x, y, z
  raw/heart_rate.jsonl — bpm
  raw/ppg.jsonl — green, IR, red
  raw/skin_temperature.jsonl — skin temperature (may be present if the watch is worn longer and the participant is at rest)
  raw/meta.json — sample counts
