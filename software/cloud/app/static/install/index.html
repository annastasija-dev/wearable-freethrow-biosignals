Install FT Watch from FT Protocol on the phone.

  1. Connect the phone and the watch to the same Wi-Fi. Galaxy Wearable must show Connected.
  2. Open FT Protocol → ⋮ → Install on watch.
  3. On the watch: Settings → Developer options → Wireless debugging On → Pair new device (leave the code on screen).
  4. On the phone: enter the code, tap Pair and install, then open FT Watch.
  5. Tap Test cloud connection, then start the session.
